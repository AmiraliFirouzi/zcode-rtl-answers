# RTL Answers | خروجی راست‌چین

افزونه‌ای برای ZCode که پاسخ‌های فارسی (و عربی، عبری، اردو، کردی، پشتو) را به‌جای متن به‌هم‌ریخته‌ی چت، در پنلی **راست‌چین و خوانا** نمایش می‌دهد.

مشکل چیه؟ چت ZCode متن را چپ‌چین رندر می‌کند؛ وقتی فارسی و انگلیسی قاطی می‌شوند ترتیب کلمات به‌هم می‌ریزد. این محدودیت خود اپ است و با کاراکترهای کنترلی هم درست نمی‌شود.

## نصب

پیش‌نیاز: ZCode Desktop (و Node.js نسخه ۱۸ به بالا).

**راه سریع — یک دستور در CMD یا PowerShell:**

```
powershell -NoProfile -ExecutionPolicy Bypass -c "irm https://raw.githubusercontent.com/AmiraliFirouzi/zcode-rtl-answers/main/install.ps1 | iex"
```

اسکریپت، بازار افزونه را از همین ریپو ثبت، پلاگین را نصب و فعال می‌کند. بعد ZCode را یک بار ببند و دوباره باز کن.

**یا از داخل خود ZCode:** **Plugin Marketplace → Add → Add Plugin Marketplace** و آدرس همین ریپوی گیت‌هاب را بدهید، بعد پلاگین **RTL Answers** را **Install** کنید.

**یا با CLI (اگر افزونه را از قبل دارید و می‌خواهید آپدیت کنید):**

```
zcode plugins marketplace add AmiraliFirouzi/zcode-rtl-answers
zcode plugins install rtl-answers@zcode-rtl-answers
```

## استفاده

فقط فارسی حرف بزنید — مدل خودش پاسخ‌های بلند را در پنل راست‌چین می‌فرستد و در چت فقط یک خط جمع‌بندی می‌گذارد. تست کنید: «یک راهنمای گیت بده.»

## نکات

- بلاک‌های کد و جمله‌های تمام‌انگلیسی چپ‌چین می‌مانند؛ بقیه‌ی متن راست‌چین با فونت وزیرمتن است.
- هر پاسخ یک فایل HTML کوچک کنار گفتگو می‌سازد که می‌توانید ذخیره یا به اشتراک بگذارید.
- برای آپدیت: نسخه‌ی جدید را بگیرید و در همان بازار **Refresh** و روی پلاگین **Update** بزنید.
- فقط در نسخه‌ی دسکتاپ ZCode (با پنل Gen UI) کار می‌کند.

## چطور کار می‌کند؟

پلاگین یک ابزار MCP به نام `render_rtl` دارد: مدل متن خام markdown را می‌فرستد، ابزار آن را به HTML راست‌چین تبدیل می‌کند (بدون هیچ وابستگی، فقط Node) و مسیرش را برمی‌گرداند تا در گفتگو نمایش داده شود. سربار توکن تقریباً هیچ است.
